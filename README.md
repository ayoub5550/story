# أمامّلن: حين تصلّبت الحجارة
### Amamellen — When the Stone Hardened

فيلم رسوم متحركة ملحمي (2D بأسلوب مرسوم يدويًا) مستوحى من أسطورة **أمامّلن / أنيغوران** عند طوارق الهقار والطاسيلي في الجزائر. الأسطورة تقابل **ملحمة جلجامش** في التراث الجزائري: حكيم يخاف أن يتجاوزه ابن أخته، فيحاول التخلص منه. ثم يفقد الفتى ويبحث عنه، وينتهي باختراع الكتابة (تيفيناغ) لتبقى الكلمة بعده.

| | |
|---|---|
| **المدة الكلية** | 22:00 دقيقة، في جزأين متصلين |
| **الجزء الأول «الحجر الليّن»** | 00:00–10:00. فيلم متصل قائم بذاته، يُنتَج أولًا |
| **الجزء الثاني «الحجر الصلب»** | 10:00–22:00 |

## محتوى المستودع
- `story/`: الملخّص، وسيناريو الجزء الأول كاملًا (S01–S09)، والمعالجة التفصيلية للجزء الثاني (S10–S18).
- `bible/`: الشخصيات والأماكن ودليل الأسلوب البصري والصوتي.
- `assets/refs/`: لوحات تصميم الشخصيات المعتمدة.
- `production/`:
  - قائمة لقطات الجزء الأول: 79 لقطة، 600 ثانية.
  - هيكل الجزء الثاني.
  - جدول المشاهد وطرق إنتاجها.
  - متتبّع التقدّم `status.md`.
- `tools/`: أدوات التحقق وبناء الأوامر (prompts) والتوليد والمونتاج.
- `renders/`: الإطارات المفتاحية واللقطات المنتَجة.

## للوكلاء (AI agents) والمساهمين
اقرأ **[AGENTS.md](AGENTS.md)** كاملًا قبل أي عمل. فيه تسلسل المرجعية، وصيغة اللقطة، والقواعد الإبداعية، وخط الإنتاج، والمهمة التالية بالضبط.

```bash
pip install pyyaml
python tools/validate_shots.py          # التحقق من قوائم اللقطات والتوقيتات
python tools/build_prompt.py S05-01     # أوامر لقطة واحدة
python tools/assemble.py --part 1       # مونتاج الجزء الأول (اللقطات الناقصة = بطاقات مؤقتة)
```
